# Estudio de un modelo simplificado de colisiones galácticas (TFG 2025-26)
En este repositorio se disponen una serie de archivos correspondientes al Trabajo Fin de Grado "Estudio de un modelo simplificado de colisiones galácticas" del alumno Ilya Shchehlik Vinogradov de la Universidad de Córdoba. Entre éstos, se incluyen el código del módulo asociado al modelo (colgal.py), el generador de simulaciones (simulaciones.py) y una serie de plots y animaciones referidas al cuerpo de texto del trabajo.

La carpeta "Anexo Figuras" está ordenada y enlazada al capítulo 3 "Resultados y discusión" del trabajo. No pudo incluirse en éste pues se superaba el límite de páginas máximo establecido por los órganos competentes de la facultad.
