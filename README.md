# Estudio de un modelo simplificado de colisiones galácticas (TFG 2025-26)

**COMENTARIO PROVISIONAL a fecha del 7 de septiembre: el repositorio está aún en construcción**

En este repositorio se disponen una serie de archivos correspondientes al Trabajo Fin de Grado "Estudio de un modelo simplificado de colisiones galácticas" del alumno Ilya Shchehlik Vinogradov de la Universidad de Córdoba; bajo la tutela de los profesores e investigadores Antonio Ortiz Mora y Beatriz Granados Ruiz. Entre estos archivos se incluyen el código del módulo asociado al modelo (colgal.py), el generador de simulaciones (simulaciones.py) y una serie de plots y animaciones referidas al cuerpo de texto del trabajo.

Las hiperfiguras e hipertablas representan el Anexo de Figuras y Tablas que se hubieran incluido en el trabajo en el caso de que la normativa sobre el límite máximo de páginas permitidas no las incluyese.
